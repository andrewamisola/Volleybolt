# Start Session Command

Run this command at the beginning of each new session.

## Instructions

1. Read `ai.context.md` in the project root for project overview
2. Read `docs/Tasks.md` for current priorities and pending work
3. Read `docs/DevLog.md` to see recent session activity
4. Summarize current state to user:
   - What was last worked on
   - What's currently in progress
   - Any blocking issues

## Output
Provide a brief "welcome back" summary with:
- Project state
- Current priorities
- Any pending items from last session
