> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 2v2 Doubles playable locally (human = Blue Front + 3 deterministic AI) on the deterministic sim, entered from the Start Battle mode-select, with singles/PvP behavior byte-identical to today.

**Architecture:** `teamSize` (1|2) threaded orthogonally to `gameMode`; back wizards are REAL sim combatants in new nullable slots `combatants.leftBack/rightBack`; `combatants.left/right` remain the FRONT wizards and carry the team-shared mana/juice/towerHealth (zero data movement — the "team pool" is the existing per-side pool). Every sim change is additive and null-back-safe so the singles goldens cannot move.

**Tech Stack:** Vanilla JS in `index.html` (inline script is authoritative), `js/sim.js` (Babylon-free deterministic sim), Babylon.js presentation.
