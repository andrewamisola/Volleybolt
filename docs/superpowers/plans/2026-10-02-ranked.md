# Ranked — implementation plan (spec: ../specs/2026-10-02-ranked-design.md)

1. **Emblems** — `tools/build_rank_icons.py`: 7 hand-placed 16x16 emblems → `textures/rank/emblems.png` (order: UNRANKED, BRONZE, SILVER, GOLD, PLATINUM, DIAMOND, MASTER).
2. **Rank module** (index.html, after Achievements): `RANK` table; pure `rankOf(mmr, games)`, `expected`, `kFor`, `deltaFor`; state load/save (`volleybolt_rank`); lifecycle `onRoundStart()` (first round of a rated match → `active` + persisted `pending`), `onMatchEnd(winnerSide)` (settle, `lastResult`), `abandon()` (resetGame while active → loss), `cancel()` (disconnect / debug end), settle a stale `pending` on load; `setOpponent({mmr, games})` for online; `window.Rank` (+ console hooks `Rank._settle(won, mode, oppMmr)` / `Rank._reset()`).
3. **Hooks** — `startRound()` (a round going live) → `Rank.onRoundStart()` (not resetRound: resetGame calls it on the way to the menu); both match-end sites (after `Achievements.evaluateMatchEnd`) → `Rank.onMatchEnd(winnerSide)`; `resetGame()` → `Rank.abandon()`; `handleDisconnect()` and `_applyDebugEnd` → `Rank.cancel()`; `hostStartDuel` adds `rank` to START_MATCH, the guest's LOADOUT reply adds `rank`; both receivers call `Rank.setOpponent`.
4. **End screen** — `renderRankCard(root)` next to the achievement strip: emblem, rank, ±MMR, animated bar, promoted/demoted/placed kicker. CSS mirrors `.end-ach` on the left band.
5. **Career → Ranked tab** — tabs become Stats / Ranked / Achievements; `careerSetTab(i)` generalised (arrows step tabs; Left off the achievements board → Ranked); `populateRanked()`: emblem card, record card, ladder strip.
6. **Verify** — console tests of the pure functions (bands, K, deltas, placement reveal, Master), a real vs-AI match (open on Go, settle on end, quit-before-Go unrated, quit-after-Go = loss, closed page = loss on next load), screenshots of Career → Ranked and the end-screen card, the determinism oracle untouched (no sim edits).
7. Commit + push (castle-spells-lighting → master), memory note.
